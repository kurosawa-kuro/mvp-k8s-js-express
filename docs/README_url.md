# 開発環境用ポート設定

## メイン開発環境
```
開発サーバー: http://localhost:3000
開発ツール: http://localhost:3000/dev
```

## データベース管理ツール

### pgAdmin（PostgreSQL管理）
```
URL: http://localhost:5050
ログイン情報：
- メール: admin@admin.com
- パスワード: admin
```

### phpMyAdmin（MySQL/MariaDB管理）
```
URL: http://localhost:8080
```

## 開発支援ツール

### Storybook（UIコンポーネント開発）
```
URL: http://localhost:6006
```

### Swagger UI（API開発・ドキュメント）
```
メインURL: http://localhost:8080/swagger-ui/
代替URL: http://localhost:8080/api-docs
```
